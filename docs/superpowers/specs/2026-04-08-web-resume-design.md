# Web履歴書デザイン仕様

## 概要

転職エージェント・採用担当者向けのWeb履歴書を GitHub Pages で公開する。
長内健作のモバイルエンジニアとしてのキャリアを簡潔に伝えるための1ページ構成のサイト。

## 要件

- **対象読者**: 転職エージェント・採用担当者
- **言語**: 日本語のみ
- **ホスティング**: GitHub Pages（リポジトリ: `tonionagauzzi/resume`）
- **ユーザーが後で加筆する前提**: 各社の業務詳細にプレースホルダーを配置

## 技術構成

- **Pure HTML/CSS**（フレームワーク・ビルドツール不使用）
- ファイル構成:
  - `index.html` — メインページ
  - `style.css` — スタイルシート

## レイアウト

**シングルカラム**。`max-width: 800px` のコンテナで中央寄せ。

### セクション順序

1. **ヘッダー** — 氏名「長内 健作」、肩書き「Android / iOS エンジニア」、最終更新日「2026年4月8日」
2. **リンク** — GitHub、ブログ、メール等のリンク（Unicode絵文字をアイコンとして使用、中央寄せで横並び）
3. **職務要約** — 3〜4行の要約文。17年以上のモバイル開発経験を要約
4. **職務経歴** — タイムライン形式（左ボーダー）。新しい順に表示:
   - サイボウズ株式会社（2022年〜現在）Androidエンジニア
   - 株式会社ACCESS（2018年〜2022年）Android/iOSエンジニア
   - 株式会社富士通ビー・エス・シー（2009年〜2018年）Android/iOSエンジニア
   - 各社に業務詳細のプレースホルダーを配置
5. **スキル** — バッジ（タグ）形式で表示: Kotlin, Swift, Java
6. **フッター** — コピーライト表記

### タイムラインの視覚表現

- 最新の職歴: `border-left: 3px solid #374151`（濃いグレー）
- 中間の職歴: `border-left: 3px solid #9ca3af`（中間グレー）
- 最古の職歴: `border-left: 3px solid #d1d5db`（薄いグレー）

## デザイン

### カラースキーム: モノクロ

| 用途 | カラーコード |
|------|-------------|
| メインカラー（見出し、ボーダー） | `#374151` |
| テキスト | `#111827` |
| サブテキスト | `#6b7280` |
| 補助テキスト | `#9ca3af` |
| バッジ背景 | `#f3f4f6` |
| バッジボーダー | `#d1d5db` |
| セクション区切り | `#e5e7eb` |
| ページ背景 | `#ffffff` |

### フォント

- **Google Fonts**: `Noto Sans JP`
- フォールバック: `sans-serif`
- 本文: `16px`
- 見出し: `font-weight: bold` + `letter-spacing: 0.05em`

### レスポンシブ対応

- モバイルファースト
- コンテナ `max-width: 800px`、左右に `padding`
- スマートフォンでも問題なく閲覧可能

### 印刷対応

- `@media print` でリンクセクションの装飾を簡略化
- 背景色を除去し、テキストのみのクリーンな出力

## GitHub Pages 設定

- リポジトリの Settings > Pages から `main` ブランチの `/` (root) をソースとして設定
- 追加の設定ファイル（`_config.yml` 等）は不要
